Fórmulas y criterios

Ventas incrementales estimadas = ventas observadas − ventas base comparables. Esta diferencia no demuestra causalidad. ROI estimado = ((ventas incrementales × margen de contribución) − inversión) / inversión. Conversión = compras / visitas. CAC = gasto de adquisición / clientes nuevos. Ejecución = inversión / presupuesto. Ahorro = horas anteriores − horas actuales. Los denominadores cero producen «No disponible».

De tus datos a una decisión.

Carga archivos, selecciona las columnas y genera un dashboard verificable. Ventas, compras, inventarios, clientes o campañas: tú defines el objetivo. Los cálculos son locales; Gemini puede ayudarte a interpretarlos.

1. Carga tus datos

Carga tu Excel .xlsx directamente y elige la hoja. Para combinar archivos de texto, deben tener las mismas columnas. JSON debe contener una lista de objetos planos. Los archivos .xls antiguos deben guardarse como .xlsx. PDF e imágenes no se leen como tablas en este módulo.

Una hoja por análisis. La fila seleccionada debe contener nombres únicos para todas las columnas de datos. Las fórmulas usan el resultado que Excel guardó.

2. Define el análisis

Filtrar datos de origen (opcional)

Coincidencia exacta. Por ejemplo: Marca = Bravecto y Tipo = Ectoparasiticida. El filtro se aplica antes de calcular y asignar.

Pesos para distribuir el presupuesto

Pesos normalizados por participación en cada factor. Deben sumar 100%. El segundo indicador se suma por grupo. Un factor sin base positiva se distribuye por igual y se declara.

Para usar solo el indicador principal: 100 / 0 / 0. Si el promedio es la operación elegida, el primer factor utiliza ese promedio. Valores negativos tienen peso cero para asignación.
